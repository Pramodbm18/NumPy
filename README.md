It is widely used in AI, machine learning, and data science projects.

📊 Example Code
import numpy as np

arr = np.array([1, 2, 3, 4])

print("NumPy Array:", arr)
print("Mean:", np.mean(arr))
print("Sum:", np.sum(arr))

Output

NumPy Array: [1 2 3 4]
Mean: 2.5
Sum: 10
